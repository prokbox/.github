# ProkBox

Free, open-source firmware for the iPod Video (5th generation and 5.5).

**[ProkBox5g](https://github.com/prokbox/prokbox5g)** is a device-tuned fork of [Rockbox](https://www.rockbox.org/) with a clean, classic-inspired interface:

- **Drag and drop.** Copy music on and off over USB. No sync app needed.
- **Every format Rockbox plays:** MP3, AAC, ALAC, FLAC, Ogg Vorbis, Opus, WAV and more.
- **Audiobooks done properly:** chapters, playback speed and a resume point for every book.
- **Free, with nothing to pay or unlock.** GPL-licensed, full source code included.

📖 **Guide and downloads:** https://prokbox.github.io/prokbox5g/ · ✉️ prokbox.project@gmail.com
