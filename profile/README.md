# ProkBox

Free, open-source firmware for older iPods, built on [Rockbox](https://www.rockbox.org/). Every ProkBox project lives here.

## Projects

| Project | For the | Status |
|---|---|---|
| **[ProkBox5g](https://github.com/prokbox/prokbox5g)** · [guide](https://prokbox.github.io/prokbox5g/) | iPod Video (5th generation and 5.5) | pre-release 0.8 |

Builds for other models may follow, and the hardware references we write along the way (the PP5022 platform, the BCM2722 video processor, the WM8758 audio codec) will get repositories of their own.

## What every ProkBox build aims for

- **Drag and drop.** Copy music on and off over USB. No sync app needed.
- **Every format Rockbox plays:** MP3, AAC, ALAC, FLAC, Ogg Vorbis, Opus, WAV and more.
- **Audiobooks done properly:** chapters, playback speed and a resume point for every book.
- **Free, with nothing to pay or unlock.** GPL-licensed, full source code included.
