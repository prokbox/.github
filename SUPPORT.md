# Getting help

- **How do I…?** Start with the guide: https://prokbox.github.io/prokbox5g/
- **Questions and ideas:** [Discussions](https://github.com/prokbox/prokbox5g/discussions)
- **Something is broken:** [open an issue](https://github.com/prokbox/prokbox5g/issues/new/choose)
- **Anything else:** prokbox.project@gmail.com

ProkBox is not Apple software, so please ask us, not Apple. If your iPod won't start, hold **MENU** while it powers on to boot Apple's own software instead.
