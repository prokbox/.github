# Security policy

ProkBox runs offline on a music player, but bugs that could damage a device, corrupt its storage or put someone's files at risk still matter to us.

**Please don't open a public issue for a security problem.** Report it privately instead:

- GitHub: the repository's **Security** tab → **Report a vulnerability**, or
- email: prokbox.project@gmail.com

We'll reply within a few days. Fixes ship in the next release, and we credit you if you'd like.
